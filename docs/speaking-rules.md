# 角色发言规则分析

> 代码：`backend/app/services/dispatch.py`（选人）、`services/persona.py`（性格适配）、
> `backend/app/agent/group_graph.py`（图编排）、`agent/group.py`（旧打分，仍用于兼容）
> 数据：实测书架「龙族大家庭」，42 名成员

---

## 0. 一句话

**发言规则在 2026-11 改成了「需求分析 -> 按性格适配选人」，不再靠外向度和阈值抽签。**

```
用户这句话
   ↓ dialogue.classify（情绪 / 强度 / 意图 / 危机）
该来几个人？1~10        该来什么人？persona.fit_for
   ↓                        ↓
   └──── 打分：适配度占 0.55 ────┘
                 ↓
          选定 1~10 个角色（并行生成）
```

---

## 1. 人数：由分析结果决定

| 场景 | 人数 | 依据 |
|---|---|---|
| 危机 | 2 | 多几个人在场，但不一窝蜂 |
| 倾诉（vent） | 2 ~ 6 | `2 + round(强度 × 4)` |
| 求助（seek_help） | 2 ~ 5 | `2 + round(强度 × 3)` |
| 闲聊（chat） | 1 ~ 3 | 强度 ≥0.5 时多来一个 |
| @全体成员 | **全员** | 用户要求所有人都回一句（安全阀 120） |
| 显式 @ | 被 @ 的 + 最多 2 | 用户指向优先 |

**硬约束**：`1 ≤ 人数 ≤ 10`。

## 2. 谁来说：性格适配度

`services/persona.py` 把「性格描述」翻译成五维向量：

| 维度 | 关键词 | 高的人适合 |
|---|---|---|
| `warmth` | 温柔/体贴/耐心/善良/包容 | 难过、疲惫、危机 |
| `energy` | 热情/开朗/话多/健谈 | 开心、闲聊 |
| `calmness` | 冷静/理性/沉稳/严肃 | 焦虑、愤怒、危机 |
| `sharpness` | 暴躁/毒舌/尖锐（**负向**） | 几乎都不适合 |
| `playfulness` | 天真/幽默/爱玩 | 开心、闲聊 |

按用户情绪加权（`FIT_WEIGHTS`）：

| 用户情绪 | 权重 |
|---|---|
| 难过 | warmth 0.60 / calmness 0.25 / **sharpness −0.45** |
| 焦虑 | warmth 0.45 / calmness 0.40 / sharpness −0.40 |
| 疲惫 | warmth 0.55 / calmness 0.25 / sharpness −0.35 |
| 愤怒 | calmness 0.55 / warmth 0.30 / sharpness −0.50 |
| 开心 | energy 0.45 / playfulness 0.40 |
| 危机 | warmth 0.55 / calmness 0.40 / sharpness −0.60 |

最终打分：

```
score = 0.60×适配度 + 0.18×相关性 + 0.10×外向度 + 0.04×arousal + 0.04×噪声
        冷却中 −0.20 ｜ 上一句是他 −0.15
```

> 噪声从 0.10 降到 0.04：之前它会把适配度只差 0.01~0.05 的人打乱，
> 结果「谁适配」被随机数盖住。现在噪声只负责打破平局。

**适配度占主导（0.55）**，这才是"难受的时候温柔的人来"能成立的原因。

## 3. 实测

```
「我今天真的撑不住了，好难过」  难过/倾诉 强度0.4 → 目标4人
   帕西 · 叶胜 · 源稚生 · 芬格尔

「我该怎么办，工作快撑不住了」  疲惫/求助 强度0.4 → 目标3人
   源稚生 · 芬格尔 · 帕西

「哈哈哈今天天气不错」        开心/闲聊 强度0.25 → 目标1人
   芬格尔

「我真的不想活了」           难过/危机 强度0.9 → 目标2人
   源稚生 · 帕西                     ← 暴躁的都不在

「@全体成员 都来说说」        平静/闲聊 → 目标10人（上限）
```

**注意**：源稚生性格是「严肃认真/责任感强/果断」→ calmness 0.99，
所以在"难过/危机"场景稳定排前——这是设计意图（稳的人来）。

## 4. 性格数据已补齐（temperament）

角色的五维性格现在**落库存着**（`characters.temperament`），不再每次靠关键词推断：

* 抽取提示词里加了 `temperament` 字段（模型按原文判断 0~1 五档）
* `library.create_character` 落库时若模型没给，就按关键词算一次
* 老角色用 `scripts/backfill_temperament.py` 回填（幂等，已有值不覆盖）

回填后的实际区分度：

| 角色 | warmth | 难过适配度 |
|---|---:|---:|
| 陈雯雯（文静/温柔/友好） | 0.99 | **0.72** |
| 樱井小暮 | 0.81 | **0.70** |
| 源稚生（严肃/责任感强） | 0.45 | 0.52 |
| 老唐 / 塞尔玛 | 0.45 | 0.29 |

跨度从 0.19 拉到 **0.43**，"温柔的人来安慰"现在是真的。

## 5. 怎么说：发言内容规则

选定人之后，每个发言人拿到的约束（`chat.py` + `dialogue.plan`）：

```
你在群聊里，用「{名字}」的身份说话：**只说 1 句，最多 2 句短话**；
不要写动作、神态、心理描写，不要复述别人说过的话。

【群聊上下文，最近几条】
用户：...
沈砚：...

【本轮判断（内部参考，不要说破）】
用户情绪：疲惫（强度 0.4）｜意图：倾诉
【应对策略】
- 以共情为主，别急着给方案
...
```

要点：

- **字数**：1~2 句（比单聊更短）
- **不写旁白**：和单聊同一条规则
- **能看到前面的人**：`transcript` 累积（**但并行时看不到同批的人**）
- **带 SOP**：和单聊同一套 `dialogue.plan` 输出
- **后置校验**：`dialogue.verify` 会在 `speaker_end` 前改写（去说教 / 安全兜底）

## 7. 建议

**最小改动（改一个数就能缓解 #1）：**

```python
group_speak_threshold: float = 0.30  →  0.15
```

0.15 低于默认期望 0.2025，普通人能过线，寡言的人（0.128）仍然不该过线——
这才符合"谁相关谁说话"的直觉。

**其他三条：**

| 问题 | 建议 |
|---|---|
| #2 `@全体` 爆炸 | 在 `all_called` 分支加 `[:max_all_speakers]`（新配置，默认 5~8），并保留"随机抽"而不是全量 |
| #3 状态不复位 | 加一个 `refresh_member_states()`：`last_spoke_at` 超过冷却期就把 `cooldown` 改回 `idle`，在 `ensure_shelf_members` 里顺手调用 |
| #4 词表太窄 | 抽取阶段就把性格规整到词表内；或对未命中的角色按 `turns`/历史发言数微调外向度 |
| #5 相关性太窄 | 加规则词：`有人/在吗/大家/谁/说点什么` → 全员相关性 +0.2（但不顶到 0.7 的"被点名"档） |
| #6 兜底失真 | 改为"分最高且不在冷却"的那位，并把噪声权重从 0.10 降到 0.05 |

---

## 8. 一句话总结

> **发言内容规则（短句、不说教、带 SOP）是合理且经过校验的；
> 发言者选择规则的阈值与数据脱节——0.30 的门槛下，42 个角色里只有约 1/3 的人
> 在 33% 的概率下靠噪声过线，于是「谁说话」实际上变成了抽签。**
>
> 把阈值调到 0.15、给 `@全体` 加人数上限，这两个改动就能让规则重新符合直觉。
